# TRON 프로세싱 설정

**TRON 프로세싱 설정** 페이지에서는 입금 지갑에서 USDT를 메인 지갑 또는 거래소로 출금할 때 네트워크 수수료를 어떤 리소스로 지불할지 선택합니다. 이 선택은 각 출금(전송) 비용에 직접적인 영향을 줍니다.

## 왜 비용이 발생하나요?

입금 지갑에서 USDT(TRC-20)를 출금하는 것은 TRON 네트워크에서의 스마트 컨트랙트 호출입니다. 이를 실행하려면 **Energy**가 필요합니다. 지갑에 Energy가 충분하지 않으면 네트워크가 TRX를 소각하여 부족분을 자동으로 보충하며, 대략 **건당 $2-5** 수준이 될 수 있습니다 (약 **65,000-130,000 Energy**).

적절한 모드를 선택하면 이러한 비용을 피하거나 크게 낮출 수 있습니다.

::: info 자세히 알고 싶나요?
TRON의 Energy, Bandwidth, 그리고 위임(delegation) 방식은 [TRON 네트워크 개요](/ko/onboarding/tron-processing-overview)에서 확인하세요.
:::

## 모드 1 - Burn TRX

입금 지갑에서 USDT를 출금할 때마다 프로세싱 지갑 잔액에서 TRX가 자동으로 소각됩니다.

**비용:** 건당 약 $2-5.

**해야 할 일:** 지갑에 TRX를 충분히 보유하기만 하면 됩니다. 나머지는 자동으로 처리됩니다.

**언제 선택:** 빠른 시작이나 테스트에 적합합니다. 별도 설정이 필요 없습니다. 거래량이 일정해지면 가장 비싼 모드가 될 수 있습니다.

## 모드 2 - Delegate cloud from DV.net

DaVinci Merchant 제공자에게서 Energy를 자동으로 임대하고, 각 트랜잭션 전에 프로세싱 지갑으로 위임합니다.

**비용:** Burn TRX 대비 **약 2배 저렴**.

**해야 할 일:** 없습니다. 현재는 남는 Energy를 무료로 공유하지만, 일부 전송은 몇 시간 정도 기다려야 할 수 있습니다.

**언제 선택:** 대부분의 머천트에게 가장 좋은 기본 선택입니다. 기술 지식이 필요 없고, 즉시 동작하며, TRX 소각보다 비용이 낮습니다.

## 모드 3 - Delegate

사용자가 직접 TRX를 자신의 지갑에서 동결(스테이킹)하고, 그로 인해 얻는 Energy를 프로세싱 지갑으로 위임합니다. 출금은 사용자 리소스를 사용해 실행됩니다.

**비용:** 건당 약 $0. 동결된 TRX는 소모되지 않으며, Energy는 24시간마다 자동으로 회복됩니다.

**해야 할 일:**

1. 메인 지갑에서 TRX를 동결합니다. 동결한 수량에 비례해 Energy를 받습니다.
2. Energy를 프로세싱 지갑 주소로 위임합니다. 주소는 설정 페이지 상단에 표시됩니다.

**언제 선택:** 출금 트래픽이 안정적이고 운영 비용을 최소화하고 싶을 때 적합합니다. 하루 약 20-30건 수준이면 빠르게 효과를 볼 수 있습니다.
