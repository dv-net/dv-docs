# 시스템 요구 사항

애플리케이션 아키텍처는 `dv-merchant`와 `dv-processing` 모듈을 서로 다른 서버에 설치할 수 있도록 설계되어 있으며, 시스템 요구사항은 모든 구성 요소를 깨끗한 운영체제가 설치된 단일 서버에 설치하는 경우를 기준으로 명시되어 있습니다.


- 4GB RAM
- 4 코어 CPU
- 30GB NVMe SSD

## 운영 체제 요구 사항

지원되는 운영 체제 버전:

- CentOS 8, 9, 10
- Debian 11, 12, 13
- Ubuntu 22.04, 24.04
- 사용하지 않는 포트 80, 8080, 9000 (구성 파일로 재정의 가능)
- 열린 포트 80

## 소프트웨어 요구 사항

분리 설치를 위해서는 다음이 필요합니다:

- Postgres 16+
- Redis 6.2+
