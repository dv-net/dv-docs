# API 없이 결제 폼 연결하기

다음의 간단한 단계에 따라 API 연동 없이 결제 폼을 연결할 수 있습니다.

또한, [이 저장소](https://github.com/dv-net/simple-payment-form)에서 연동 예시를 확인할 수 있습니다.

## 1. 스토어의 결제 링크 찾기

프로젝트 계정에 로그인한 뒤 **Projects**, **Edit**, **Advanced settings**로 이동하세요.

그곳에서 **API 없이 사용하는 결제 폼 링크**를 확인할 수 있으며, 이 링크에는 스토어의 **UUID**(고유 식별자)가 포함되어 있습니다.

## 2. 결제 링크 수정하기

다음 형식을 사용하여 결제 링크를 생성하세요:

### 항목 설명:

- `{your-domain-or-subdomain}`: 등록된 도메인 또는 서브도메인입니다.
- `{store-uuid}`: 스토어의 UUID입니다(스토어 링크에 표시됨).
- `{client-id}`: 링크를 생성할 때 부여하는 고유한 클라이언트 식별자입니다. 결제 추적 및 원하는 클라이언트 지갑과의 연결에 필요합니다.

> ⚠️ **중요:** `client-id`는 정확한 추적과 식별을 위해 각 클라이언트 세션마다 고유해야 합니다.

---

링크를 생성한 후에는 해당 링크로 클라이언트를 리디렉션하거나, 사이트의 버튼에 링크를 삽입하여 사용할 수 있습니다.
