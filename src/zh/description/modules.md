# 应用模块

## 主要模块

应用程序由三个模块组成：
- `dv-merchant` - 该模块包括 Web 服务器、用于显示支付表单和控制面板的前端、与第三方交易所交互的代码，以及创建项目、客户钱包、向商店发送 Webhook 和转发收到的加密货币的全部业务逻辑。
- `dv-processing` - 该模块存储助记词，并根据 `dv-merchant` 的指令签署交易。
- `dv-updater` - 该模块负责自动更新，由 `dv-merchant` 管理。

## 其他软件包

生态系统中提供了可用于安装和配置辅助服务（如 PostgreSQL、Redis 等）的额外软件包和工具。其组成和安装方式可能因操作系统和应用程序的具体构建而有所不同

## 应用部署与用户权限

所有应用模块均安装在 `/home/dv` 目录下。
系统会自动创建用户 `dv:dv`，用于运行应用服务并管理配置文件。

像 PostgreSQL 和 Redis 这样的服务，通过操作系统的标准工具或随应用提供的自动化工具进行安装。它们使用系统默认账户和标准端口（除非在配置中另有指定）。
服务的自动启动由 `systemd` 管理。
