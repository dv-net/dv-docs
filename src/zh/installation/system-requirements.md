# 系统要求

应用架构允许将 dv-merchant 和 dv-processing 模块安装在不同的服务器上；系统要求基于在一台干净的操作系统服务器上进行单服务器安装的方案列出。

- 4GB 内存 (RAM)
- 4 核中央处理器 (CPU)
- 30GB NVMe 固态硬盘 (SSD)

## 操作系统要求

支持的操作系统版本：

- CentOS 8, 9, 10
- Debian 11, 12, 13
- Ubuntu 22.04, 24.04
- 未被占用的端口 80、8080、9000（可以通过配置文件重新定义）
- 开放的端口 80

## 进行分离式安装时，需要具备：

进行分离式安装时，需要具备：

- Postgres 16+
- Redis 6.2+
