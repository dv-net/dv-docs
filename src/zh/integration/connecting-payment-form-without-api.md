# 在不使用 API 的情况下连接支付表单

您可以按照以下简单步骤，在无需集成 API 的情况下连接支付表单。

此外，您还可以在[此仓库](https://github.com/dv-net/simple-payment-form)中查看集成示例。

## 1. 查找您商店的支付链接

登录您的项目账户，前往 **项目**、**编辑**、**高级设置**。

在那里您会找到**无需 API 的支付表单链接**，其中包含您商店的 **UUID**（唯一标识符）。

## 2. 修改支付链接

使用以下格式生成支付链接：

### 说明：

- `{your-domain-or-subdomain}` 是您注册的域名或子域名。
- `{store-uuid}` 是您商店的 UUID（在商店链接中指定）。
- `{client-id}` 是您在生成链接时分配的唯一客户标识符。它用于跟踪支付并将其关联到相应的客户钱包。

> ⚠️ 重要：`client-id` 必须在每个客户会话中唯一，以确保正确的跟踪和识别。

---

生成链接后，您可以将客户重定向到该链接，或将其嵌入到您网站的按钮中。
