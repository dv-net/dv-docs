# DV.net WooCommerce प्लगइन के साथ WordPress पर क्रिप्टो भुगतान स्वीकार करें

अपने ई-कॉमर्स स्टोर में क्रिप्टो पेमेंट गेटवे को एकीकृत करना आपके ग्राहक आधार को बढ़ाने और आधुनिक, सुरक्षित भुगतान विकल्प देने का एक बेहतरीन तरीका है। DV.net इन लेन-देन को संभालने के लिए एक शक्तिशाली समाधान प्रदान करता है, और इसका समर्पित WooCommerce प्लगइन इंटीग्रेशन प्रक्रिया को सरल बनाता है।
यह गाइड आपको चरण-दर-चरण आपके WordPress साइट पर DV.net WooCommerce प्लगइन इंस्टॉल और कॉन्फ़िगर करने में सहायता करेगा।

## आवश्यकताएँ:

- एक सक्रिय WordPress वेबसाइट।
- WooCommerce प्लगइन इंस्टॉल और सक्रिय हो।
- एक सक्रिय DV.net अकाउंट।

## Step 1: DV.net WooCommerce प्लगइन प्राप्त करें

पहला कदम प्लगइन फ़ाइलें डाउनलोड करना है। आधिकारिक WordPress रिपॉज़िटरी वाले प्लगइन्स के विपरीत, आपको यह प्लगइन DV.net GitHub पेज से मिलेगा।

आधिकारिक DV.net WooCommerce प्लगइन रिपॉज़िटरी पर जाएँ: https://github.com/dv-net/dv-woocommerce (यह आपको आपकी फाइलों में प्रदान किया गया था)।
- दाएँ मेनू में Releases सेक्शन पर क्लिक करें।
- आखिरी वर्ज़न के मेनू से "Source code (zip)" चुनें।
- .zip फ़ाइल अपने कंप्यूटर पर सेव करें। इसे अनज़िप न करें।

## Step 2: अपने WordPress साइट पर प्लगइन इंस्टॉल करें

अब आप डाउनलोड की गई ZIP फ़ाइल को अपने WordPress एडमिन डैशबोर्ड पर अपलोड करेंगे।
1. अपने WordPress एडमिन क्षेत्र में लॉग इन करें (उदा., yourdomain.com/wp-admin)।
2. बाएँ मेनू से Plugins > Add New पर जाएँ।
3. "Add Plugins" पेज के शीर्ष पर Upload Plugin बटन पर क्लिक करें।
4. "Choose File" बटन पर क्लिक करें और अभी डाउनलोड की गई dv-woocommerce-main.zip फ़ाइल चुनें।
5. Install Now पर क्लिक करें।
6. WordPress द्वारा प्लगइन इंस्टॉल करना पूरा होने के बाद Activate Plugin बटन पर क्लिक करें।
अब आपको अपने सक्रिय प्लगइन्स की सूची में "DV.net WooCommerce Plugin" दिखाई देगा।

## Step 3: अपने DV.net API क्रेडेंशियल्स प्राप्त करें

प्लगइन को काम करने के लिए, आपको API keys का उपयोग करके इसे अपने DV.net अकाउंट से कनेक्ट करना होगा।

1. अपने DV.net अकाउंट डैशबोर्ड में लॉग इन करें।
2. API Keys सेक्शन पर जाएँ (obtaining-api-key-and-secret.md फाइल के आधार पर)।
3. "Create New Key" बटन पर क्लिक करें।
4. अपनी key को एक वर्णनात्मक नाम दें (उदा., "WooCommerce Store")।
5. सिस्टम एक API Key और API Secret जनरेट करेगा।
6. महत्वपूर्ण: API Key और API Secret दोनों को कॉपी करें और उन्हें किसी सुरक्षित स्थान, जैसे पासवर्ड मैनेजर, में सेव करें। इस पेज से बाहर जाने के बाद आप सीक्रेट को दोबारा नहीं देख पाएँगे।
7. अपने API URL पर भी ध्यान दें। यह आपके DV.net इंस्टेंस का मुख्य URL है (उदा., https://api.your-dv-instance.com)।

## Step 4: WooCommerce में DV.net गेटवे कॉन्फ़िगर करें

अब जब आपके पास API keys हैं, तो आप WooCommerce के अंदर प्लगइन की सेटिंग्स कॉन्फ़िगर कर सकते हैं।

1. अपने WordPress डैशबोर्ड में WooCommerce > Settings पर जाएँ।
2. पेज के शीर्ष पर Payments टैब पर क्लिक करें।
3. आपको पेमेंट मेथड्स की सूची में "DV.net" दिखाई देगा। दाएँ तरफ Manage बटन पर क्लिक करें।
4. इससे DV.net सेटिंग्स पेज खुलेगा। निम्न फ़ील्ड्स भरें (जो हमें class-dv-gateway.php फाइल में मिले):
   1. Enable/Disable: चेकआउट पर इस पेमेंट मेथड को उपलब्ध कराने के लिए "Enable DV.net" बॉक्स को चेक करें।
   2. Title: यह वह टेक्स्ट है जो ग्राहक पेमेंट मेथड चुनते समय देखेंगे। उदाहरण: "DV.net के माध्यम से क्रिप्टो से भुगतान करें"।
   3. Description: यह शीर्षक के नीचे दिखाई देने वाला छोटा टेक्स्ट है। उदाहरण: "क्रिप्टोकरेंसी से सुरक्षित भुगतान करें।"
   4. API URL: Step 3 में नोट किया हुआ API URL पेस्ट करें।
   5. API Key: Step 3 में जनरेट की गई API Key पेस्ट करें।
   6. API Secret: Step 3 में सेव किया हुआ API Secret पेस्ट करें।
   7. Webhook Secret: यह सुरक्षा के लिए एक महत्वपूर्ण फ़ील्ड है। आपको एक मज़बूत, यूनिक सीक्रेट वाक्यांश बनाना चाहिए (उदा., पासवर्ड जनरेटर का उपयोग करके)। इसे DV.net और आपके स्टोर के बीच साझा किए जाने वाले पासवर्ड की तरह समझें। इस सीक्रेट को सेव कर लें, क्योंकि इसकी आवश्यकता अगले स्टेप में होगी।
5. पेज के नीचे Save changes बटन पर क्लिक करें।

## Step 5: अपने DV.net अकाउंट में वेबहुक कॉन्फ़िगर करें

अब आपका स्टोर DV.net को पेमेंट रिक्वेस्ट भेजने के लिए तैयार है। अंतिम कदम एक वेबहुक सेट करना है ताकि DV.net आपके स्टोर को पेमेंट स्टेटस अपडेट्स (जैसे "Paid" या "Failed") वापस भेज सके।

1. अपने DV.net अकाउंट डैशबोर्ड पर वापस जाएँ।
2. Webhooks या Developer सेक्शन पर जाएँ।
3. एक नया वेबहुक बनाएँ।
4. Payload URL: यह सबसे महत्वपूर्ण हिस्सा है। आपके स्टोर का यूनिक वेबहुक URL है: https://yourdomain.com/wc-api/dv_gateway/ (याद रखें yourdomain.com को अपनी वास्तविक वेबसाइट एड्रेस से बदलें। सुनिश्चित करें कि यह https:// का उपयोग करता है)।
5. Secret: वही Webhook Secret पेस्ट करें जो आपने Step 4 में बनाया और सेव किया था। इसका उपयोग यह सत्यापित करने के लिए किया जाता है कि आने वाले अनुरोध वास्तव में DV.net से हैं (जैसा कि webhook-signature-verification.md में बताया गया है)।
6. Events: यदि पूछा जाए, तो वे इवेंट्स चुनें जिन्हें यह वेबहुक सुनना चाहिए। आपको सभी भुगतान-संबंधित इवेंट्स सक्षम करने चाहिए, जैसे:
   1. payment.completed
   2. payment.failed
   3. invoice.paid (नोट: सटीक इवेंट नाम अलग हो सकते हैं। वे सभी चुनें जो पेमेंट स्टेटस बदलाव से संबंधित हों।)
7. अपने DV.net डैशबोर्ड में वेबहुक को सेव करें और सक्रिय करें।

Step 6: सब सेट! (टेस्ट करना न भूलें)

बधाई हो! DV.net पेमेंट गेटवे अब आपके WooCommerce स्टोर के साथ पूरी तरह एकीकृत हो चुका है।

अंत में एक लाइव टेस्ट चलाएँ। इसका सबसे अच्छा तरीका:
1. अपने स्टोर पर ऐसे जाएँ जैसे आप ग्राहक हों।
2. किसी वास्तविक प्रोडक्ट को अपने कार्ट में जोड़ें।
3. चेकआउट पेज पर जाएँ।
4. "DV.net के माध्यम से क्रिप्टो से भुगतान करें" (या वह शीर्षक जो आपने सेट किया है) चुनें।
5. ऑर्डर प्लेस करें और सुनिश्चित करें कि आपको सही तरीके से DV.net पेमेंट पेज पर रीडायरेक्ट किया जा रहा है।
6. हम ज़ोर देकर सलाह देते हैं कि एक छोटा टेस्ट ट्रांज़ैक्शन पूरा करें ताकि यह सुनिश्चित हो सके कि भुगतान सफल होने के बाद आपके WooCommerce Orders सेक्शन में ऑर्डर स्टेटस "Pending payment" से "Processing" या "Completed" में अपने-आप अपडेट हो जाता है।

यदि ऑर्डर स्टेटस अपने-आप अपडेट हो जाता है, तो आपका इंटीग्रेशन सफल है!
