# DV.net Payment Gateway एक्सटेंशन के साथ OpenCart पर क्रिप्टो पेमेंट्स कैसे स्वीकार करें

क्रिप्टोकरेंसी पेमेंट्स ऑफर करने से आपका OpenCart स्टोर काफी बेहतर हो सकता है, व्यापक ऑडियंस आकर्षित होती है और आधुनिक पेमेंट लचीलापन मिलता है। DV.net एक मजबूत क्रिप्टो पेमेंट प्रोसेसिंग समाधान प्रदान करता है, और इसका OpenCart एक्सटेंशन इंटीग्रेशन प्रक्रिया को सरल बनाता है।
यह गाइड आपके OpenCart वेबसाइट पर DV.net पेमेंट गेटवे एक्सटेंशन को इंस्टॉल और कॉन्फ़िगर करने के लिए एक स्पष्ट, चरण-दर-चरण मार्गदर्शिका देता है।

## पूर्वापेक्षाएँ:

- एक सक्रिय OpenCart वेबसाइट।
- आपके OpenCart डैशबोर्ड का एडमिन एक्सेस।
- एक सक्रिय DV.net खाता।

## चरण 1: DV.net OpenCart एक्सटेंशन प्राप्त करें

सबसे पहले, आपको एक्सटेंशन फाइलें डाउनलोड करनी होंगी। आप इन्हें आधिकारिक DV.net GitHub रिपॉज़िटरी से प्राप्त करेंगे।

- आधिकारिक DV.net OpenCart एक्सटेंशन रिपॉज़िटरी पर जाएँ: https://github.com/dv-net/dv-opencart.
- Releases पेज पर जाएँ
- `dv-opencart-vX.X.X.ocmod.zip` डाउनलोड करें

## चरण 2: अपने OpenCart साइट पर एक्सटेंशन इंस्टॉल करें

OpenCart अपलोड संभालने के लिए Extension Installer का उपयोग करता है।

- अपने OpenCart एडमिन डैशबोर्ड में लॉग इन करें (उदा., yourdomain.com/admin).
- बाएँ मेनू से Extensions > Installer पर जाएँ।
- Upload बटन पर क्लिक करें।
- चरण 1 में डाउनलोड की गई .zip फाइल चुनें।
- अपलोड और इंस्टॉलेशन प्रक्रिया पूरी होने तक प्रतीक्षा करें। आपको एक सफलता संदेश दिखेगा।
- महत्वपूर्ण: इंस्टॉलेशन के बाद, Extensions > Modifications पर जाएँ और सिस्टम को बदलाव पहचानने के लिए ऊपर-दाएँ कोने में नीला Refresh बटन क्लिक करें।
- यह भी अच्छा होगा कि आप अपना थीम कैश साफ करें। Dashboard पर जाएँ, ऊपर-दाएँ कोने में नीला Settings (कोग) आइकन क्लिक करें, और फिर Theme Cache तथा SASS Cache के लिए Refresh बटनों पर क्लिक करें।

## चरण 3: अपने DV.net API क्रेडेंशियल्स प्राप्त करें

अपने स्टोर को DV.net से जोड़ने के लिए आपको API Key, API Secret, और API URL की आवश्यकता होगी।

- अपने DV.net अकाउंट डैशबोर्ड में लॉग इन करें।
- API Keys सेक्शन में जाएँ (डॉक्युमेंटेशन फाइलों में obtaining-api-key-and-secret.md देखें)।
- "Create New Key" पर क्लिक करें।
- कुंजी को एक प्रासंगिक नाम दें (उदा., "OpenCart Store")।
- सिस्टम आपकी API Key और API Secret प्रदर्शित करेगा।
- महत्वपूर्ण: तुरंत API Key और API Secret दोनों को कॉपी करें और उन्हें सुरक्षित रूप से संग्रहीत करें (उदा., पासवर्ड मैनेजर में)। Secret दोबारा नहीं दिखाया जाएगा।
- अपने API URL को नोट करें, जो आपकी DV.net इंस्टेंस का बेस URL है (उदा., https://api.your-dv-instance.com).

## चरण 4: OpenCart में DV.net Gateway कॉन्फ़िगर करें

अब, अपने OpenCart एडमिन पैनल में पेमेंट मेथड कॉन्फ़िगर करें।

- अपने OpenCart डैशबोर्ड में Extensions > Extensions पर जाएँ।
- "Choose the extension type" लेबल वाले ड्रॉपडाउन से Payments चुनें।
- सूची में नीचे स्क्रॉल करें जब तक कि "DV.net Gateway" न मिल जाए। यदि यह पहले से इंस्टॉल नहीं है तो हरे Install (+) बटन पर क्लिक करें, और फिर नीले Edit (पेंसिल) बटन पर क्लिक करें।
- इससे DV.net कॉन्फ़िगरेशन पेज खुलता है। निम्न विवरण भरें (admin/controller/extension/payment/dv_gateway.php और संबंधित language/template फाइलों के आधार पर):
- API URL: चरण 3 से API URL पेस्ट करें।
- API Key: चरण 3 से API Key पेस्ट करें।
- API Secret: चरण 3 से API Secret पेस्ट करें।

## चरण 5: अपना इंटीग्रेशन टेस्ट करें!

- आपका DV.net OpenCart इंटीग्रेशन अब पूरा होना चाहिए! एक टेस्ट ट्रांज़ैक्शन करना आवश्यक है।
- अपने OpenCart स्टोर के फ्रंट एंड पर जाएँ।
- अपनी कार्ट में कोई प्रोडक्ट जोड़ें।
- चेकआउट प्रक्रिया आगे बढ़ाएँ।
- पेमेंट मेथड चुनते समय "DV.net Gateway" चुनें (या जो टाइटल कॉन्फ़िगर किया गया हो; अक्सर OpenCart एक्सटेंशनों में यह फिक्स्ड होता है)।
- ऑर्डर कन्फर्म करें। आपको DV.net पेमेंट पेज पर रीडायरेक्ट किया जाना चाहिए।
- कड़ाई से सिफारिश: एक छोटा, वास्तविक ट्रांज़ैक्शन पूरा करें। DV.net पर पेमेंट सफल होने के बाद, अपने OpenCart एडमिन पैनल > Sales > Orders पर वापस जाएँ। सत्यापित करें कि टेस्ट ऑर्डर की स्थिति अपने आप आपकी 'Pending' स्थिति से 'Paid' स्थिति (उदा., 'Processing' या 'Complete') में अपडेट हो गई है।
यदि ऑर्डर स्टेटस बिना मैन्युअल हस्तक्षेप के सही ढंग से अपडेट हो जाता है, तो आपका सेटअप सफल है! अब ग्राहक आपके OpenCart स्टोर पर DV.net के माध्यम से क्रिप्टोकरेंसी का उपयोग करके भुगतान कर सकते हैं।
