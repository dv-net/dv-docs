# API का उपयोग किए बिना पेमेंट फ़ॉर्म कनेक्ट करना

इन सरल चरणों का पालन करके आप बिना API इंटीग्रेशन के पेमेंट फ़ॉर्म कनेक्ट कर सकते हैं।

इसके अलावा, आप इंटीग्रेशन का उदाहरण [इस रिपॉज़िटरी में](https://github.com/dv-net/simple-payment-form) देख सकते हैं।

## 1. अपने स्टोर का पेमेंट लिंक खोजें

अपने प्रोजेक्ट खाते में लॉग इन करें और **Projects**, **Edit**, **Advanced settings** पर जाएँ।

वहाँ आपको **link to the payment form without API** मिलेगा, जिसके अंदर आपके स्टोर का **UUID** (यूनिक आइडेंटिफ़ायर) होता है।

## 2. पेमेंट लिंक संशोधित करें

पेमेंट लिंक जनरेट करने के लिए निम्न फ़ॉर्मेट का उपयोग करें:

### जहाँ:

- `{your-domain-or-subdomain}` आपका रजिस्टर्ड डोमेन या सबडोमेन है।
- `{store-uuid}` आपके स्टोर का UUID है (स्टोर लिंक में निर्दिष्ट)।
- `{client-id}` एक यूनिक क्लाइंट आइडेंटिफ़ायर है जिसे आप लिंक जनरेट करते समय असाइन करते हैं। यह भुगतान को ट्रैक करने और उसे इच्छित क्लाइंट वॉलेट से जोड़ने के लिए आवश्यक है।

> ⚠️ **महत्वपूर्ण:** `client-id` प्रत्येक क्लाइंट सेशन के लिए यूनिक होना चाहिए ताकि सही ट्रैकिंग और पहचान सुनिश्चित हो सके।

---

लिंक जनरेट होने के बाद, आप क्लाइंट को उस पर रीडायरेक्ट कर सकते हैं या अपनी साइट पर किसी बटन में उसे एम्बेड कर सकते हैं।
