# قبول مدفوعات العملات الرقمية على WordPress باستخدام إضافة DV.net الخاصة بـ WooCommerce

يُعد دمج بوابة دفع بالعملات الرقمية في متجرك الإلكتروني طريقة ممتازة لتوسيع قاعدة عملائك وتقديم خيارات دفع عصرية وآمنة. توفّر DV.net حلاً قوياً لمعالجة هذه المعاملات، وتُبسّط إضافتها المخصّصة لـ WooCommerce عملية الدمج بشكل كبير.
سيرشدك هذا الدليل، خطوة بخطوة، إلى كيفية تثبيت وتهيئة إضافة DV.net لـ WooCommerce على موقع WordPress الخاص بك.

## المتطلبات الأساسية:

- موقع WordPress نشط.
- تثبيت وتفعيل إضافة WooCommerce.
- حساب نشط على DV.net.

## الخطوة 1: الحصول على إضافة DV.net لـ WooCommerce

تتمثل الخطوة الأولى في تنزيل ملفات الإضافة. بخلاف الإضافات الموجودة في مستودع WordPress الرسمي، ستحصل على هذه الإضافة من صفحة GitHub الخاصة بـ DV.net.

انتقل إلى مستودع الإضافة الرسمي الخاص بـ DV.net على GitHub: https://github.com/dv-net/dv-woocommerce (تم توفيره في ملفاتك).
- انقر قسم Releases في القائمة على اليمين.
- اختر "Source code (zip)" من قائمة آخر إصدار.
- احفظ ملف .zip على جهازك. لا تفك ضغطه.

## الخطوة 2: تثبيت الإضافة على موقع WordPress الخاص بك

الآن ستقوم برفع ملف ZIP الذي نزّلته إلى لوحة تحكم WordPress.
1. سجّل الدخول إلى منطقة إدارة WordPress الخاصة بك (مثال: yourdomain.com/wp-admin).
2. من القائمة اليسرى، انتقل إلى Plugins > Add New.
3. في أعلى صفحة "Add Plugins"، انقر زر Upload Plugin.
4. انقر زر "Choose File" واختر الملف dv-woocommerce-main.zip الذي نزّلته للتو.
5. انقر Install Now.
6. بعد أن ينتهي WordPress من تثبيت الإضافة، انقر زر Activate Plugin.
سترى الآن "DV.net WooCommerce Plugin" ضمن قائمة الإضافات المفعّلة.

## الخطوة 3: الحصول على بيانات اعتماد واجهة برمجة التطبيقات (API) من DV.net

قبل أن تعمل الإضافة، يجب ربطها بحسابك على DV.net باستخدام مفاتيح API.

1. سجّل الدخول إلى لوحة حسابك في DV.net.
2. انتقل إلى قسم API Keys (استناداً إلى ملف obtaining-api-key-and-secret.md).
3. انقر زر "Create New Key".
4. امنح المفتاح اسماً وصفياً (مثال: "WooCommerce Store").
5. سيُنشئ النظام API Key و API Secret.
6. مهم: انسخ كلّاً من API Key و API Secret واحفظهما في مكان آمن، مثل مدير كلمات المرور. لن تتمكن من رؤية السر مرة أخرى بعد مغادرتك هذه الصفحة.
7. دوّن أيضاً API URL. هذا هو عنوان URL الرئيسي لواجهة DV.net الخاصة بك (مثال: https://api.your-dv-instance.com).

## الخطوة 4: تهيئة بوابة DV.net في WooCommerce

بعد حصولك على مفاتيح API، يمكنك الآن ضبط إعدادات الإضافة داخل WooCommerce.

1. في لوحة WordPress، انتقل إلى WooCommerce > Settings.
2. انقر علامة التبويب Payments في أعلى الصفحة.
3. سترى "DV.net" في قائمة طرق الدفع. انقر زر Manage في أقصى اليمين.
4. سيفتح هذا صفحة إعدادات DV.net. املأ الحقول التالية (كما في ملف class-dv-gateway.php):
   1. Enable/Disable: ضع علامة على "Enable DV.net" لجعل طريقة الدفع هذه متاحة عند إتمام الشراء.
   2. Title: هذا النص يراه العملاء عند اختيار طريقة الدفع. مثال: "Pay with Crypto via DV.net".
   3. Description: نص قصير يظهر تحت العنوان. مثال: "Securely pay with cryptocurrency."
   4. API URL: ألصق API URL الذي دوّنته في الخطوة 3.
   5. API Key: ألصق API Key الذي أنشأته في الخطوة 3.
   6. API Secret: ألصق API Secret الذي حفظته في الخطوة 3.
   7. Webhook Secret: هذا حقل بالغ الأهمية للأمان. يجب أن تنشئ عبارة سرية قوية وفريدة (مثلاً باستخدام مولّد كلمات مرور). اعتبرها كلمة مرور مشتركة بين DV.net ومتجرك. احفظ هذا السر، فستحتاجه في الخطوة التالية.
5. انقر زر Save changes أسفل الصفحة.

## الخطوة 5: إعداد الـ Webhook في حسابك على DV.net

أصبح متجرك الآن معدّاً لإرسال طلبات الدفع إلى DV.net. الخطوة الأخيرة هي إعداد Webhook ليتمكن DV.net من إرسال تحديثات حالة الدفع (مثل "Paid" أو "Failed") إلى متجرك.

1. عد إلى لوحة حسابك في DV.net.
2. انتقل إلى قسم Webhooks أو Developer.
3. أنشئ Webhook جديداً.
4. Payload URL: هذا هو الجزء الأهم. عنوان Webhook الفريد لمتجرك هو: https://yourdomain.com/wc-api/dv_gateway/ (تذكّر استبدال yourdomain.com بعنوان موقعك الفعلي. تأكّد من استخدام https://).
5. Secret: ألصق نفس Webhook Secret الذي أنشأته وحفظته في الخطوة 4 تماماً. يُستخدم هذا للتحقق من أن الطلبات الواردة صادرة فعلاً من DV.net (كما ورد في ملف webhook-signature-verification.md).
6. Events: إذا طُلِب منك ذلك، اختر الأحداث التي يجب أن يستمع لها هذا الـ Webhook. ينبغي تفعيل كل الأحداث المتعلقة بالدفع، مثل:
   1. payment.completed
   2. payment.failed
   3. invoice.paid (ملاحظة: قد تختلف الأسماء الدقيقة للأحداث. اختر كل ما يتعلق بتغيّرات حالة الدفع.)
7. احفظ وفعّل الـ Webhook من لوحة DV.net.

الخطوة 6: كل شيء جاهز! (لا تنسَ الاختبار)

تهانينا! تم دمج بوابة دفع DV.net بالكامل مع متجر WooCommerce الخاص بك.

تبقّى إجراء اختبار حي. أفضل طريقة للقيام بذلك هي:
1. اذهب إلى متجرك كما لو كنت عميلاً.
2. أضف منتجاً حقيقياً إلى سلة التسوق.
3. انتقل إلى صفحة إتمام الشراء.
4. اختر "Pay with Crypto via DV.net" (أو العنوان الذي ضبطته).
5. أكمل الطلب وتأكد من أنه تم تحويلك بشكل صحيح إلى صفحة الدفع الخاصة بـ DV.net.
6. نوصي بشدة بإجراء معاملة اختبارية صغيرة للتأكد من تحديث حالة الطلب تلقائياً في قسم طلبات WooCommerce من "Pending payment" إلى "Processing" أو "Completed" بعد نجاح الدفع.

إذا تم تحديث حالة الطلب تلقائياً، فهذا يعني أن التكامل ناجح!
