# كيفية قبول مدفوعات العملات المشفّرة على OpenCart باستخدام إضافة بوابة الدفع DV.net

يوفّر قبول مدفوعات العملات المشفّرة تحسيناً كبيراً لمتجر OpenCart الخاص بك، إذ يجذب جمهوراً أوسع ويمنح مرونة دفع حديثة. تقدّم DV.net حلاً قوياً لمعالجة مدفوعات العملات المشفّرة، وتعمل إضافتها لـ OpenCart على تبسيط عملية التكامل.
يوفّر هذا الدليل شرحاً واضحاً خطوة بخطوة لتثبيت وتهيئة إضافة بوابة الدفع DV.net على موقع OpenCart الخاص بك.

## المتطلبات المسبقة:

- موقع OpenCart فعّال.
- وصول إداري إلى لوحة تحكم OpenCart.
- حساب DV.net فعّال.

## الخطوة 1: الحصول على إضافة DV.net لـ OpenCart

أولاً، تحتاج إلى تنزيل ملفات الإضافة. ستحصل عليها من مستودع DV.net الرسمي على GitHub.

- انتقل إلى مستودع إضافة DV.net الرسمي لـ OpenCart: https://github.com/dv-net/dv-opencart.
- انتقل إلى صفحة Releases
- قم بتنزيل `dv-opencart-vX.X.X.ocmod.zip`

## الخطوة 2: تثبيت الإضافة على موقع OpenCart الخاص بك

يستخدم OpenCart أداة Extension Installer للتعامل مع عمليات الرفع.

- سجّل الدخول إلى لوحة الإدارة في OpenCart (مثال: yourdomain.com/admin).
- من القائمة اليسرى، انتقل إلى Extensions > Installer.
- انقر زر Upload.
- اختر ملف ‎.zip‎ الذي قمت بتنزيله في الخطوة 1
- انتظر حتى تكتمل عملية الرفع والتثبيت. ينبغي أن تظهر رسالة نجاح.
- مهم: بعد التثبيت، انتقل إلى Extensions > Modifications ثم انقر زر Refresh الأزرق في الزاوية العليا اليمنى لتأكيد تعرّف النظام على التغييرات.
- كما يُستحسن مسح ذاكرة التخزين المؤقت للقالب. انتقل إلى Dashboard، وانقر أيقونة Settings (شكل الترس) الزرقاء في أعلى اليمين، ثم انقر أزرار Refresh لكلٍ من Theme Cache و SASS Cache.

## الخطوة 3: الحصول على بيانات اعتماد واجهة برمجة التطبيقات (API) من DV.net

لربط متجرك بـ DV.net، تحتاج إلى API Key و API Secret و API URL.

- سجّل الدخول إلى لوحة حسابك في DV.net.
- انتقل إلى قسم API Keys (راجع obtaining-api-key-and-secret.md ضمن ملفات التوثيق).
- انقر "Create New Key".
- امنح المفتاح اسماً مناسباً (مثال: "OpenCart Store").
- سيعرض النظام API Key و API Secret الخاصين بك.
- هام جداً: انسخ كلاً من API Key و API Secret فوراً واحفظهما بأمان (مثال: في مدير كلمات مرور). لن يتم عرض السر مرة أخرى.
- دوّن API URL لديك، وهو عنوان الأساس لنُسخة DV.net الخاصة بك (مثال: https://api.your-dv-instance.com).

## الخطوة 4: تهيئة بوابة DV.net في OpenCart

الآن، قم بتهيئة طريقة الدفع من داخل لوحة إدارة OpenCart.

- في لوحة OpenCart، انتقل إلى Extensions > Extensions.
- من القائمة المنسدلة "Choose the extension type"، اختر Payments.
- مرّر في القائمة حتى تجد "DV.net Gateway". انقر زر Install الأخضر (+) إذا لم تكن مثبّتة بعد، ثم انقر زر Edit الأزرق (رمز القلم).
- سيُفتح بذلك صفحة إعدادات DV.net. املأ التفاصيل التالية (استناداً إلى admin/controller/extension/payment/dv_gateway.php وملفات اللغة/القوالب المرتبطة):
- API URL: الصق API URL من الخطوة 3.
- API Key: الصق API Key من الخطوة 3.
- API Secret: الصق API Secret من الخطوة 3.

## الخطوة 5: اختبار التكامل!

- يُفترض الآن اكتمال تكامل DV.net مع OpenCart! من الضروري إجراء معاملة اختبار.
- قم بزيارة الواجهة الأمامية لمتجر OpenCart الخاص بك.
- أضِف منتجاً إلى سلة التسوق.
- تابع عملية الدفع.
- عند اختيار طريقة الدفع، اختر "DV.net Gateway" (أو العنوان المضبوط، مع أنه غالباً ثابت في إضافات OpenCart).
- أكّد الطلب. يجب أن يتم تحويلك إلى صفحة الدفع الخاصة بـ DV.net.
- مُنصَح بشدة: أكمِل معاملة حقيقية صغيرة. بعد نجاح الدفع على DV.net، عُد إلى لوحة إدارة OpenCart > Sales > Orders. تحقّق من أن حالة طلب الاختبار قد تم تحديثها تلقائياً من 'Pending' إلى حالة 'Paid' (مثل 'Processing' أو 'Complete').
إذا تم تحديث حالة الطلب بشكل صحيح دون تدخّل يدوي، فهذا يعني أن الإعداد ناجح! بات بإمكان العملاء الآن الدفع بالعملات المشفّرة عبر DV.net على متجر OpenCart الخاص بك.
