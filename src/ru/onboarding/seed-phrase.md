# Сид-фраза: экспорт, импорт и поиск депозитных адресов

Сид-фраза (seed phrase) — это мастер-ключ вашего мерчанта. Из неё математически выводятся все адреса горячих кошельков. Зная сид-фразу, можно восстановить доступ к любому адресу и найти все когда-либо сгенерированные депозитные адреса.

> ⚠️ **Сид-фраза — самый чувствительный секрет вашей системы.** Тот, кто её знает, имеет доступ ко всем кошелькам. Храните её офлайн, в защищённом месте, никогда не передавайте третьим лицам.


## Как экспортировать сид-фразу

1. Перейдите в **Transfers → Hot Wallets**
2. Нажмите кнопку **Download seed phrases** в правом верхнем углу страницы
3. Пройдите двухфакторную аутентификацию (Two-factor authentication)
4. Сохраните файл в надёжном месте

> Рекомендуется хранить сид-фразу на бумаге или на офлайн-устройстве, не подключённом к интернету.


## Как импортировать сид-фразу в кошелёк

Импорт сид-фразы позволяет получить доступ ко всем адресам мерчанта через стандартный криптовалютный кошелёк.

### MetaMask (EVM-сети)

1. Установите [MetaMask](https://metamask.io)
2. На экране приветствия выберите **Import an existing wallet**
3. Введите сид-фразу (12 или 24 слова) в указанном порядке
4. Задайте пароль и завершите настройку
5. Переключитесь на нужную сеть в верхнем меню

> MetaMask поддерживает все EVM-совместимые сети: Ethereum, Base, BNB Chain, Polygon, Arbitrum и другие.

### OKX Wallet (EVM + BTC + другие сети)

1. Установите [OKX Wallet](https://www.okx.com/web3)
2. Выберите **Import wallet → Seed phrase**
3. Введите сид-фразу в указанном порядке
4. Задайте пароль и завершите настройку
5. В разделе кошельков выберите нужную сеть или монету

> OKX Wallet поддерживает EVM-сети, Bitcoin, Bitcoin Cash и многие другие — это рекомендуемый вариант при работе с несколькими сетями одновременно.


## Как найти депозитные адреса по сид-фразе

DV.net генерирует депозитные адреса по стандартным путям деривации (derivation paths). Зная сид-фразу, вы можете воспроизвести любой адрес вручную.

### Стандартные пути деривации

| Сеть | Путь деривации |
|---|---|
| Ethereum и все EVM-сети | `m/44'/60'/0'/0/N` |
| Bitcoin (Legacy) | `m/44'/0'/0'/0/N` |
| Bitcoin (SegWit) | `m/84'/0'/0'/0/N` |
| Bitcoin Cash | `m/44'/145'/0'/0/N` |

Где `N` — порядковый номер адреса (0, 1, 2, ...). Первый сгенерированный адрес соответствует `N=0`, второй — `N=1` и так далее.

### Как найти конкретный адрес

Для поиска адреса по сид-фразе удобнее всего использовать специализированный инструмент, который сразу показывает весь список выводимых адресов с их индексами и приватными ключами.

#### Инструмент: iancoleman BIP39

[iancoleman.io/bip39](https://iancoleman.io/bip39/) — браузерный инструмент с открытым исходным кодом. Работает полностью офлайн: страницу можно сохранить и открыть без интернета.

> ⚠️ **Вводите сид-фразу только офлайн.** Перед использованием сохраните страницу через «Сохранить как» в браузере, отключите интернет и только потом вводите сид-фразу. Никогда не вводите её на чужих устройствах или при активном подключении к сети.

**Как пользоваться:**

1. Откройте [iancoleman.io/bip39](https://iancoleman.io/bip39/) и сохраните страницу офлайн (Ctrl+S / Cmd+S)
2. Отключите интернет и откройте сохранённый файл в браузере
3. В поле **BIP39 Mnemonic** введите сид-фразу
4. В разделе **Coin** выберите нужную монету:
   - `ETH — Ethereum` для всех EVM-сетей (Ethereum, Base, BNB Chain, Polygon и др.)
   - `BTC — Bitcoin` для Bitcoin Legacy или SegWit
   - `BCH — Bitcoin Cash` для Bitcoin Cash
5. В разделе **Derivation Path** выберите вкладку в соответствии с нужным стандартом:
   - **BIP44** — для EVM-адресов и Bitcoin Legacy (`m/44'/...`)
   - **BIP84** — для Bitcoin SegWit (`m/84'/...`)
6. В разделе **Derived Addresses** отобразится таблица адресов с колонками: путь, адрес, публичный ключ, приватный ключ
7. Найдите нужный адрес в таблице — сверьте с адресом из транзакции
8. Скопируйте соответствующий приватный ключ для импорта в кошелёк

По умолчанию отображаются адреса с индексами 0–19. Для просмотра следующих — нажмите **Show more rows** или укажите начальный индекс в поле **starting from index**.

> Большинство адресов находятся в диапазоне 0–1000. Если адрес не найден в первых 20 — увеличивайте диапазон шагами по 20.
