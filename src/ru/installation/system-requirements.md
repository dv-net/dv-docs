# Системные требования

Архитектура приложения позволяет устанавливать модули `dv-merchant` и `dv-processing` на разные сервера, системные
требования указаны для варианта установки на одном сервере на чистой операционной системе

- 4GB RAM
- 4 Core CPU
- 30GB NVMe SSD

# Требования к операционной системе

Поддерживаемые версии операционных систем:

- CentOS 8, 9, 10
- Debian 11, 12, 13
- Ubuntu 22.04, 24.04
- Незанятые порты 80, 8080, 9000 (могут быть переопределены файлом конфигурации)
- Открытый порт 80

# Требования к программному обеспечению

Для раздельной установки требуется наличие:

- Postgres 16+
- Redis 6.2+
