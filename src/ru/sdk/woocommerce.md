# Принимайте криптоплатежи в WordPress с плагином DV.net для WooCommerce

Интеграция криптоплатёжного шлюза в ваш интернет‑магазин — отличный способ расширить клиентскую базу и предложить современные и безопасные способы оплаты. DV.net предоставляет мощное решение для обработки таких транзакций, а специализированный плагин для WooCommerce упрощает процесс интеграции.
Это руководство по шагам проведёт вас через установку и настройку плагина DV.net для WooCommerce на вашем сайте WordPress.

## Предварительные требования:

- Активный сайт на WordPress.
- Плагин WooCommerce установлен и активирован.
- Активная учётная запись DV.net.

## Шаг 1: Получите плагин DV.net для WooCommerce

Сначала скачайте файлы плагина. В отличие от плагинов из официального репозитория WordPress, этот нужно получить со страницы DV.net на GitHub.

Перейдите в официальный репозиторий плагина DV.net для WooCommerce: https://github.com/dv-net/dv-woocommerce (Адрес указан в ваших материалах).
- В правом меню нажмите раздел Releases.
- В меню последней версии выберите «Source code (zip)».
- Сохраните .zip‑файл на компьютер. Не распаковывайте его.

## Шаг 2: Установите плагин на ваш сайт WordPress

Теперь загрузите скачанный ZIP‑файл в админ‑панель WordPress.
1. Войдите в админ‑панель WordPress (например, yourdomain.com/wp-admin).
2. В левом меню откройте Plugins > Add New.
3. Вверху страницы «Add Plugins» нажмите кнопку Upload Plugin.
4. Нажмите кнопку «Choose File» и выберите файл dv-woocommerce-main.zip, который вы только что скачали.
5. Нажмите Install Now.
6. После завершения установки нажмите кнопку Activate Plugin.
Теперь в списке активных плагинов вы увидите «DV.net WooCommerce Plugin».

## Шаг 3: Получите учётные данные API DV.net

Прежде чем плагин сможет работать, подключите его к своей учётной записи DV.net с помощью API‑ключей.

1. Войдите в панель управления своей учётной записью DV.net.
2. Перейдите в раздел API Keys (согласно файлу obtaining-api-key-and-secret.md).
3. Нажмите кнопку «Create New Key».
4. Дайте ключу понятное имя (например, «WooCommerce Store»).
5. Система сгенерирует API Key и API Secret.
6. Важно: Скопируйте и сохраните API Key и API Secret в надёжном месте (например, в менеджере паролей). После ухода со страницы Secret больше не будет виден.
7. Также запишите ваш API URL — это основной URL вашего экземпляра DV.net (например, https://api.your-dv-instance.com).

## Шаг 4: Настройте шлюз DV.net в WooCommerce

Имея на руках API‑ключи, настройте параметры плагина в WooCommerce.

1. В панели WordPress откройте WooCommerce > Settings.
2. Нажмите вкладку Payments вверху страницы.
3. В списке способов оплаты появится «DV.net». Нажмите кнопку Manage справа.
4. Откроется страница настроек DV.net. Заполните следующие поля (указаны в файле class-dv-gateway.php):
   1. Enable/Disable: установите флажок «Enable DV.net», чтобы сделать этот способ оплаты доступным на кассе.
   2. Title: текст, который увидит покупатель при выборе способа оплаты. Например: «Оплатить криптовалютой через DV.net».
   3. Description: краткий текст под заголовком. Например: «Безопасная оплата криптовалютой».
   4. API URL: вставьте API URL, записанный на шаге 3.
   5. API Key: вставьте API Key, созданный на шаге 3.
   6. API Secret: вставьте API Secret, сохранённый на шаге 3.
   7. Webhook Secret: критически важное поле безопасности. Создайте сильную уникальную секретную фразу (например, с помощью генератора паролей). Это «пароль», который будут знать DV.net и ваш магазин. Сохраните его — он понадобится на следующем шаге.
5. Нажмите кнопку Save changes внизу страницы.

## Шаг 5: Настройте вебхук в своей учётной записи DV.net

Теперь ваш магазин настроен на отправку платёжных запросов в DV.net. Осталось настроить вебхук, чтобы DV.net мог отправлять обратно в ваш магазин обновления статуса платежей (например, «Paid» или «Failed»).

1. Вернитесь в панель управления учётной записью DV.net.
2. Перейдите в раздел Webhooks или Developer.
3. Создайте новый вебхук.
4. Payload URL: это самый важный параметр. Уникальный URL вебхука вашего магазина: https://yourdomain.com/wc-api/dv_gateway/ (Не забудьте заменить yourdomain.com на адрес вашего сайта и использовать https://).
5. Secret: вставьте тот же Webhook Secret, который вы создали и сохранили на шаге 4. Он используется для проверки, что входящие запросы действительно от DV.net (см. webhook-signature-verification.md).
6. Events: при необходимости выберите события, на которые должен подписаться вебхук. Включите все события, связанные с платежами, например:
   1. payment.completed
   2. payment.failed
   3. invoice.paid (Примечание: точные названия событий могут отличаться. Выберите все, что связаны с изменениями статуса платежа.)
7. Сохраните и активируйте вебхук в панели DV.net.

Шаг 6: Всё готово! (Не забудьте протестировать)

Поздравляем! Платёжный шлюз DV.net полностью интегрирован с вашим магазином на WooCommerce.

Осталось провести боевой тест. Лучше всего сделать так:
1. Перейдите в магазин как обычный покупатель.
2. Добавьте любой реальный товар в корзину.
3. Перейдите на страницу оформления заказа.
4. Выберите «Pay with Crypto via DV.net» (или ваш вариант заголовка).
5. Создайте заказ и убедитесь, что вас корректно перенаправляет на платёжную страницу DV.net.
6. Настоятельно рекомендуем выполнить небольшой тестовый платёж, чтобы убедиться, что статус заказа в разделе Orders в WooCommerce автоматически меняется с «Pending payment» на «Processing» или «Completed» после успешной оплаты.

Если статус заказа обновляется автоматически — интеграция прошла успешно!
