# Как принимать криптоплатежи в OpenCart с расширением платежного шлюза DV.net

Прием криптовалюты может существенно улучшить ваш магазин на OpenCart, привлечь более широкую аудиторию и дать современную гибкость оплаты. DV.net предлагает надежное решение для обработки криптоплатежей, а его расширение для OpenCart упрощает интеграцию.
В этом руководстве приведены понятные пошаговые инструкции по установке и настройке расширения платежного шлюза DV.net на вашем сайте OpenCart.

## Предварительные требования:

- Активный сайт на OpenCart.
- Администраторский доступ к панели управления OpenCart.
- Активная учетная запись DV.net.

## Шаг 1: Загрузите расширение DV.net для OpenCart

Сначала необходимо скачать файлы расширения. Их можно получить из официального репозитория DV.net на GitHub.

- Перейдите в официальный репозиторий расширения DV.net для OpenCart: https://github.com/dv-net/dv-opencart.
- Откройте страницу Releases
- Скачайте `dv-opencart-vX.X.X.ocmod.zip`

## Шаг 2: Установите расширение на ваш сайт OpenCart

В OpenCart для загрузок используется установщик расширений.

- Войдите в панель администратора OpenCart (например, yourdomain.com/admin).
- В левом меню перейдите в Extensions > Installer.
- Нажмите кнопку Upload.
- Выберите .zip‑файл, который вы скачали на Шаге 1
- Дождитесь завершения загрузки и установки. Должно появиться сообщение об успешном выполнении.
- Важно: после установки перейдите в Extensions > Modifications и нажмите синюю кнопку Refresh в правом верхнем углу, чтобы система применила изменения.
- Также рекомендуется очистить кэш темы. Перейдите в Dashboard, нажмите синюю иконку шестеренки Settings в правом верхнем углу, затем нажмите кнопки Refresh для Theme Cache и SASS Cache.

## Шаг 3: Получите учетные данные API DV.net

Чтобы подключить магазин к DV.net, вам понадобятся API Key, API Secret и API URL.

- Войдите в панель управления своей учетной записи DV.net.
- Перейдите в раздел API Keys (см. obtaining-api-key-and-secret.md в файлах документации).
- Нажмите «Create New Key».
- Дайте ключу понятное имя (например, «OpenCart Store»).
- Система отобразит ваш API Key и API Secret.
- Важно: сразу скопируйте и безопасно сохраните и API Key, и API Secret (например, в менеджере паролей). Секрет больше не будет показан.
- Запишите свой API URL — базовый URL вашего экземпляра DV.net (например, https://api.your-dv-instance.com).

## Шаг 4: Настройте шлюз DV.net в OpenCart

Теперь настройте способ оплаты в панели администратора OpenCart.

- В панели OpenCart перейдите в Extensions > Extensions.
- В выпадающем меню «Choose the extension type» выберите Payments.
- Прокрутите список до «DV.net Gateway». Нажмите зеленую кнопку Install (+), если модуль еще не установлен, затем нажмите синюю кнопку Edit (карандаш).
- Откроется страница настройки DV.net. Заполните следующие поля (согласно admin/controller/extension/payment/dv_gateway.php и связанным файлам языка/шаблонов):
- API URL: вставьте API URL из Шага 3.
- API Key: вставьте API Key из Шага 3.
- API Secret: вставьте API Secret из Шага 3.

## Шаг 5: Протестируйте интеграцию!

- Интеграция DV.net с OpenCart должна быть завершена! Важно выполнить тестовую транзакцию.
- Зайдите на витрину вашего магазина OpenCart.
- Добавьте товар в корзину.
- Перейдите к оформлению заказа.
- При выборе способа оплаты выберите «DV.net Gateway» (или настроенный заголовок, хотя в расширениях OpenCart он часто фиксированный).
- Подтвердите заказ. Вас должно перенаправить на платежную страницу DV.net.
- Настоятельно рекомендуется: выполните небольшую реальную оплату. После успешного платежа в DV.net вернитесь в панель администратора OpenCart > Sales > Orders. Убедитесь, что статус тестового заказа автоматически изменился с вашего статуса 'Pending' на статус 'Paid' (например, 'Processing' или 'Complete').
Если статус заказа обновляется корректно без ручного вмешательства, настройка выполнена успешно! Теперь клиенты могут оплачивать заказы криптовалютой через DV.net в вашем магазине OpenCart.
